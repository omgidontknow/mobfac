# mobfac

Mobile-friendly sand factory prototype game.

This repository contains a small web prototype (HTML/CSS/JS) demonstrating a sand-particle factory game designed for mobile browsers. The prototype is committed on the branch `add/sand-factory-prototype` for future development.

See files:
- index.html
- styles.css
